Tg-ban

A Python-based Telegram project.

📥 Installation (Termux)

1. Update Termux

pkg update && pkg upgrade -y

2. Install Git and Python

pkg install git python -y

3. Clone Repository

git clone https://github.com/sajjadulkhanabir143/Tg-ban.git

4. Open Project Folder

cd Tg-ban

5. Install Requirements

pip install -r requirements.txt

6. Run the Project

Check the project files for the correct entry-point filename, then run:

python tool.py

Replace "filename.py" with the actual Python file name.

🛠 Requirements

- Termux
- Python 3
- Git
- Internet connection
